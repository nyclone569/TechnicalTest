# Soulslike
This is **a soulslike game project**, inspired by Stellar Blade and Elden Ring, mainly focused on combat mechanics (parry and counter) and enemy AI. 
This project is developed using **Unreal Engine 5**, with the goal of learning how to use UE with a data-driven mindset and solid architecture design patterns.

- Genre: Soulslike, Action RPG.
- Target: Learn Unreal Engine 5 and build fundamental systems for a soulslike game.
- Concept: Inspired by Stellar Blade and Elden Ring, with focus on combat and AI.

## 📌 Current Features
- **Player Core**: Input, movement and camera.
- **Attribute system (GAS)**: Health, poise, attack, defense, counter stack.
- **Combat (GAS)**: Equip weapon, light/heavy/mix combo attacks, block, parry, counter attack, directional rolling, perfect dodge, target lock, hit reaction and death.
- **Enemy AI**: small melee mobs with hit reaction, stun and death abilities, using behavior tree with idle, chase, strafe and attack states.
- **UI**: basic player info (health, weapon icon, counter stack and target lock point) and enemy info (health and poise bar).
